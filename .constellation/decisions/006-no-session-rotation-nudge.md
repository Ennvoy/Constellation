# 006 移除「提醒使用者換 session」——收束句整條刪除

背景：`phase-build.md` 的「收束句」規定 build 階段整合完一批平行票後，要收束本 session、催使用者開新 session 續下一批，理由是長 session 判斷力退化。使用者表示不需要這種提醒。

決定：整條刪除，不留改寫版。「換 session 讀檔即接手」的**能力**描述照舊保留（`DESIGN.md` §1 第 3 點、§4 接續段、`SKILL.md` 判斷依據那條）——那些在講機制怎麼運作，不是在催使用者。此後工作流不主動建議使用者換 session 或收束對話，何時換由使用者自己決定。

原因：節奏控制權屬於使用者，工作流不代為判斷；而刪掉催促後剩下的「這是完成點、隨時可接續」只是重述 `DESIGN.md` §1「狀態全部外部化成檔案，換 session 讀檔即接手」，留著是重複條文，違背極簡（§0：機制省下的時間要超過它消耗的時間）。代價是批與批之間沒有明文停點，工作流會一批接一批做到使用者喊停——這正是使用者要的自主權。

證據：使用者原話「我覺得我不需要你提醒我換 session，可以把這條準則拿掉」；彈窗「要刪多深？」在「整條刪掉（推薦）」「只刪催促、留完成點」「連其他地方一起掃」中選了「整條刪掉（推薦）」。當時依據：無實測數據，屬使用者自主權偏好。
