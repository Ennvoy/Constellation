# 出貨報告：出貨鎖改成每個專案一把

## 做了什麼

本輪票號：T-001（小流程，單一任務卡；決議 033）

- **T-001 出貨鎖改成每個專案一把**：出貨前整套完整測試（`--scope ship`）的使用中燈，範圍從「整台機器一把」縮成「每個專案一把」。兩個不同專案同時出貨時各自開跑、不排隊，只在開跑與紅燈收尾時印一行提醒；同一個專案（含同一個 repo 的其他工作區）同時出貨時，後到的排隊等先到的。殺行程守門仍護著所有專案的出貨全量，並修正兩個會讓整條殺行程指令提前放行的縫：「持有者已死」與「同 session」兩種登記改成只跳過那一份、繼續檢查下一份；同 session 只有在自己的專案裡動手才放行；`evidence.cjs` 壞掉時守門仍照擋。不新增機制、不新增設定欄位。決議 033 落檔，決議 026、032 檔頭加註被取代；`DESIGN.md`、`README.md`、`CONTEXT.md`、`SKILL.md`、`phase-ship.md`、`verification-playbook.md` 與 `lease.mjs`、`kill-guard.mjs` 檔頭註解措辭同步。
